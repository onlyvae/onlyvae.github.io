根目录下大部分目录均为只读目录，只有`/private/`下的几个目录可以进行写入操作，主要的数据写入都在`/var` 目录下。
> 可以用mount命令来查看挂载的目录是否是read-only。


1. `/Developer`

    开发者目录，默认为空，只有当手机连接Xcode调试App时，Xcode会在该目录挂载 `DeveloperDiskImage.dmg` iOS开发者磁盘映像，提供代码调试功能(debugserver)。

2. `/System/Library`
    
    系统核心组件目录，其中：
    - `/System/Library/Frameworks` 和 `/System/Library/PrivateFrameworks` 
    存放了iOS大部分的系统库。大量私有API需要逆向分析这些Framework。
    - `/System/Library/CoreServices/SpringBoard.app`
    iOS系统桌面程序，在手机桌面上进行交互操作都是在和SpringBoard进程进行交互，许多iOS桌面美化插件都是对SpringBoard进行Hook。
3. `/var/containers/Bundle/Application` 

    应用程序安装目录，包括部分苹果系统应用和App Store安装的应用，单个应用的目录结构：
    
    ```c
    /var/containers/Bundle/Application/9CD71F37-4E0A-4275-9AC4-9E91CD2A5ABB
    |-- .com.apple.mobile_container_manager.metadata.plist
    |-- BundleMetadata.plist
    |-- Facebook.app
    |-- iTunesMetadata.plist
    ```
    
    应用程序放在其中的`xxx.app`目录中，`.com.apple.mobile_container_manager.metadata.plist` 文件记录了应用程序的bundleID，可过通过搜索应用的bundleID来找到应用的安装路径：
    
    ```bash
    find /var/containers/Bundle/Application -name "*.metadata.plist" | \
        xargs grep -l "com.facebook.Facebook" | \
        xargs -I{} dirname {}
    ```
    
4. `/var/mobile/Containers/Data/Application` 
    
    应用数据目录，单个应用的目录结构：
    
    ```bash
    /var/mobile/Containers/Data/Application/1ED354AA-69C1-45F3-8802-34056C9CCDEC
    |-- .com.apple.mobile_container_manager.metadata.plist
    |-- Documents
    |-- Library
    |-- SystemData
    |-- tmp
    ```
    
    其中`.com.apple.mobile_container_manager.metadata.plist`记录了应用程序的bundleID，可通过以下命令来搜索目标应用的数据目录：
    
    ```jsx
    find /var/mobile/Containers/Data/Application -name "*.metadata.plist" | \
        xargs grep -l "com.facebook.Facebook" | \
        xargs -I{} dirname {}
    ```
    
5. `/var/mobile/Containers/Shared/AppGroup` 

    App Group（应用组）目录，同一开发者下的多个App可通过创建AppGroup目录来共享数据。
    
    系统自带的文件管理器中的下载目录就存放在AppGroup目录中，搜索命令：
    
    ```jsx
    find /var/mobile/Containers/Shared/AppGroup -type d -name "Downloads" \
         -path "*/File Provider Storage/*" 2>/dev/null
    ```
    
6. `/var/Keychains/keychain-2.db`

    钥匙串数据库文件，通常存放密钥、用户凭据等敏感数据，数据库中保存的是加密信息，无法直接解密。

7. `/var/mobile/Library/Logs/CrashReporter` 
    
    应用或系统崩溃时日志目录。

8. `/var/mobile/Library/Preferences`
    
    偏好设置目录，存放大量系统应用的配置文件

1. `/rootfs`

    原始系统根目录。

2. `/usr/lib/TweakInject/` 
   
    tweak插件目录：
